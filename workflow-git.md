# Les workflow de git

commit -> état d'un projet enregistré dans l'espace de travail. Peut être considéré comme une "étape" dans le projet.

branch -> pointeur sur un commit. Peut être retrouvé directement par son nom, ce qui est une amélioration ergonomique non négligeable.

push -> envoie d'un commit dans l'espace de travail.

pull request -> Récupération d'un commit se trouvant sur l'espace de travail commun. Demande à connaitre l'adresse de la source avant de se faire ("origin").

merge -> la combinaison de deux commits. Peut échouer si leur contenu sont considérés comme incompatibles (modifications sur la même ligne, actions contradictoires, etc...).
